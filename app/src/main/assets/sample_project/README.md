# Mobile Code Workspace

Welcome to **Mobile Code**, a full-featured Android Development Environment with Visual Studio Code Desktop UX.

## Features
- **Monaco Code Editor**: Multi-tab editing, line numbers, dirty file indicators.
- **Integrated Terminal**: Run interactive Linux Android shell commands (`pwd`, `ls`, `cat`, etc.).
- **Node.js & Python**: Build and run modern server apps directly on your device.
- **Physical & Virtual Keyboard**: Support for physical keyboard shortcuts (`Ctrl+S`, `Ctrl+Shift+P`, `Ctrl+\``) and custom coding accessory bar.

## Quick Commands
- Toggle Terminal: `Ctrl + \`` or tap the Terminal icon in Activity Bar
- Command Palette: `Ctrl + Shift + P`
- Save File: `Ctrl + S`
